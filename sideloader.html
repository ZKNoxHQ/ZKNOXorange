ZKNOX Orange

Load custom applications onto your Ledger device in development mode. Perfect for developers building and testing Ledger apps.

⚠️ Development Mode

This tool is intended for developers testing their own applications.

1. Device

Put your Ledger device in Dashboard mode (main menu, no app open)

Disconnected

ZKNOX Apps Catalog

One-click install a pre-built ZKNOX application onto your connected device.

3. Load Application

4. Custom CA

Push a custom Certificate Authority to enable sideloading. Device must be in Recovery Mode.

📱 How to enter Recovery Mode

Flex: Turn off → Hold button near USB → Connect USB → Release at "Recovery"

Stax: Turn off → Hold upper-left corner → Connect USB

Nano S/S+/X: Hold left button → Connect USB → Release at "Recovery"

Uses test CA with private key = 1 (secp256k1 generator point G as public key)
